# Acme Home & Living — example brand kit

This is a fictional brand kit for "Acme Home & Living," shipped with this repo
to demonstrate the brand-kit schema described in `brand-kit/SCHEMA.md`.
Every name, color, address, link, and product in this folder is invented —
it does not correspond to any real company.

To use it with a skill, point the skill at this folder: "use the brand kit at
`<repo>/brand-kit/example`."
